# 任务启动

阅读 `docs/rules/task-intake.md`，使用 `docs/templates/task-intake.md` 输出，不在 skill 内维护第二套字段真值。

## 触发条件

当请求还没有稳定 task 对象，或需要明确范围/风险时使用。

## 反向采访

- 先探索可发现事实，不询问仓库、配置或现有代码已经能回答的问题。
- 每次只问一个问题；优先问回答变化会改变架构、安全、接口、数据、验证或上线策略的问题。
- 命中认证、权限、全局请求层等红区，或用户声明不了解关键模块时，先做盲点审查，再补任务启动块。

## 禁止项

验收标准不清或红区确认缺失时，不得开始实现。
