# 前端 UI 工程

先读取设计系统、现有组件和数据契约。实现完整 loading、empty、error、disabled、success 与权限状态；保持键盘访问、焦点、语义标签、响应式布局和可理解错误反馈。数据转换留在既有边界，不在视图臆造接口字段。复用现有组件，避免无必要抽象。使用 `frontend-implementation-check` 核对实现；浏览器工具可用时使用 `browser-verification`，不可用则回退到明确的人工步骤并列出未验证项。
