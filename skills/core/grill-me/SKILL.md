# 结构化追问

先探索仓库能回答的事实，只询问产品意图、取舍或授权边界。每次提出一个会改变架构、契约、安全、数据、上线或验收的关键问题，并给出推荐默认值及影响。持续更新已确认决策与剩余未知，直到实现者无需猜测；低影响细节采用仓库惯例并记录假设。无法获得关键答案时输出阻塞项和最小可继续范围，不开始越权实现。
