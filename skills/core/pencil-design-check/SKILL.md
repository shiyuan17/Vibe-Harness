# Pencil 设计检查

处理 Pencil 设计资产时确认：

1. 已识别源 `.pen` 文件，不直接用普通读写工具处理加密内容。
2. 需要视觉判断时导出或查看预览图。
3. 变更遵守既有设计系统、变量和组件边界。
4. 交付包含设计文件、预览证据和实现注意事项。
5. 无法验证视觉结果时，明确剩余风险。

不要把截图当成可编辑源文件。不要绕过 Pencil 工具链直接改 `.pen`。
