# 表单工艺

表单工程的具象模式与契约。强制门禁见 `docs/rules/frontend-rules.md`；组件状态变体见 `component-states.md`。

## 提交行为

| 控件 | 行为 | 为什么 |
|---|---|---|
| 单一文本输入 | 聚焦时 Enter 提交 | 用户预期表单的默认行为 |
| 多控件表单 | Enter 应用到末尾文本输入提交 | 多输入时逐个 Enter 不应误触提交 |
| `<textarea>` | `⌘/Ctrl+Enter` 提交；Enter 换行 | 多行输入需要 Enter 换行，组合键提交区分语义 |

## 标签与关联

| 要求 | 做法 | 为什么 |
|---|---|---|
| 每个控件有标签 | 用 `<label for>` 关联，或控件嵌套在 `<label>` 内 | 屏幕阅读器依赖关联朗读控件用途 |
| 标签激活 | 点击 `<label>` 聚焦关联控件 | 扩大命中区，移动端尤其重要 |
| 图标按钮命名 | 纯图标按钮提供描述性 `aria-label` | 无文字时辅助技术需要名称 |
| 不暴露 schema | 视觉布局可省可见标签，但 accessible name 仍存在 | 视觉简洁与可访问性兼顾 |

## 提交与校验

| 要求 | 做法 | 为什么 |
|---|---|---|
| 提交启用规则 | 提交开始前保持启用；提交中禁用并显示 spinner；含幂等键 | 预禁用提交则用户无法触发校验反馈 |
| 不阻止输入 | 数值字段也允许任意输入，显示校验反馈 | 过早阻止输入阻碍修正与粘贴 |
| 不预禁用提交 | 允许提交不完整表单以暴露校验 | 校验反馈比禁用更 educative |
| 幂等键 | 提交请求携带幂等键 | 防止重复提交产生副作用 |
| 错误定位 | 错误显示在字段旁；提交时聚焦首个错误 | 用户立即知道哪里出错、如何修复 |
| 错误文案 | 告诉用户如何修复，不只说明出了什么错 | 可操作的错误信息降低挫败感 |

## 字段类型与输入模式

| 要求 | 做法 | 为什么 |
|---|---|---|
| 正确 `type` | 用 `email`/`tel`/`url`/`number` 等语义类型 | 触发对应键盘与浏览器校验 |
| 正确 `inputmode` | 配合 `inputmode` 精确控制键盘 | `numeric`/`decimal`/`search` 等匹配输入意图 |
| `autocomplete` 与 `name` | 设置有意义的 `name` 和 `autocomplete` 令牌 | 启用浏览器自动填充与密码管理器 |
| 选择性 spellcheck | 邮箱、代码、用户名等禁用 spellcheck | 拼写检查对非自然语言无意义且干扰 |
| Windows `<select>` | 显式设置 `background-color` 和 `color` | Windows 下默认值在暗色模式对比度异常 |

## 占位符与未保存

| 要求 | 做法 | 为什么 |
|---|---|---|
| 占位符信号 | 占位符以省略号结尾，表示空状态 | 区分占位文本与真实值 |
| 占位符值 | 设为示例值或模式（如 `+1 (123) 456-7890`） | 示例比抽象描述更易理解 |
| 占位符非标签 | 占位符不替代 `<label>` | 占位符输入后消失，无持久标识 |
| 未保存变更 | 有未保存数据时导航前警告（`beforeunload` 或路由守卫） | 防止意外丢失输入 |

## 密码管理器与 2FA

| 要求 | 做法 | 为什么 |
|---|---|---|
| 兼容密码管理器 | auth 字段用标准 `autocomplete` 令牌（`current-password`/`new-password`） | 密码管理器依赖标准令牌识别 |
| 允许粘贴验证码 | 一次性代码字段允许粘贴 | 用户从短信/认证器复制，禁用粘贴阻断流程 |
| 非 auth 字段不触发 | 非 auth 字段避免保留 name；用 `autocomplete="off"` 或 `one-time-code` | 防止密码管理器误识别非密码字段 |
| 输入法空白 | 裁剪输入法追加的尾部空白 | 部分输入法追加空格导致代码校验失败 |

## 复选框与单选

| 要求 | 做法 | 为什么 |
|---|---|---|
| 无死区 | checkbox/radio 与其 `<label>` 共享单一命中目标 | 分离的命中区导致点击 label 不生效 |
| 分组标签 | 用 `<fieldset>` + `<legend>` 标注分组 | 屏幕阅读器朗读分组上下文
