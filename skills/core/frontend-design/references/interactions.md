# 交互工艺

具象交互工程技术，覆盖键盘、焦点、触控、滚动、反馈与状态导航。强制门禁见 `docs/rules/frontend-rules.md`；组件状态变体见 `component-states.md`。

## 键盘与焦点

| 要求 | 做法 | 为什么 |
|---|---|---|
| 全键盘可操作 | 所有交互流程按 WAI-ARIA Authoring Patterns 实现 | 键盘与辅助技术用户依赖 Tab/Enter/Space/箭头/Esc |
| 可见焦点环 | 用 `:focus-visible` 而非 `:focus`；分组控件用 `:focus-within` | `:focus` 在鼠标点击时也显示，打扰鼠标用户；`:focus-visible` 仅键盘聚焦时呈现 |
| 禁止无替代的 `outline: none` | 若移除默认 outline，必须提供可见焦点替代（边框、box-shadow 或 outline 偏移） | 无焦点环则键盘用户无法定位当前位置 |
| 焦点陷阱与归还 | Dialog/Drawer 打开时焦点锁定在其内；关闭后焦点归还触发元素 | 防止焦点逃逸到背景层，符合 WAI-ARIA Dialog 模式 |
| 焦点顺序 | DOM 顺序与视觉阅读顺序一致；不依赖 `tabindex` 正整数重排 | 正整数 `tabindex` 打乱自然顺序，维护成本高 |

## 触控与命中目标

| 要求 | 阈值/做法 | 为什么 |
|---|---|---|
| 命中目标 | 桌面 ≥24px；移动端 ≥44px | 小于阈值难以精准点击，违反 WCAG 2.5.5/2.5.8 |
| 视觉与命中一致 | 若视觉元素小于阈值，用透明 padding 扩大命中区 | 视觉紧凑但触控友好 |
| 移动输入字号 | `<input>` font-size ≥16px | iOS Safari 低于 16px 会自动放大页面 |
| 禁用浏览器缩放 | 不得使用 `user-scalable=no` 或 `maximum-scale=1` | 缩放是无障碍权利，禁用违反 WCAG 1.4.4 |
| 双击缩放抑制 | `touch-action: manipulation` | 移除 300ms 延迟并阻止双击缩放，保留单击 |
| 点击高亮 | 设置 `-webkit-tap-highlight-color` 匹配设计 | 默认灰色高亮破坏视觉一致性 |

## 滚动与溢出

| 要求 | 做法 | 为什么 |
|---|---|---|
| 滚动隔离 | 模态/抽屉内滚动用 `overscroll-behavior: contain` | 防止滚动链穿透到背景层 |
| 滚动持久化 | 前进/后退恢复先前滚动位置 | 用户期望回到原位而非顶部 |
| 标题锚点 | 标题设 `scroll-margin-top` | 跳转时固定头部不遮挡标题 |
| 滚动条 | 只在有用时渲染；用 macOS"始终显示滚动条"测试溢出 | 残留滚动条造成布局抖动与视觉噪音 |
| 让浏览器布局 | 优先 flex/grid/intrinsic 布局，避免 JS 测量 | JS 测量触发 layout thrash，性能差 |

## 反馈与状态

| 要求 | 做法 | 为什么 |
|---|---|---|
| 加载按钮 | 显示指示器并保留原始标签 | 保留标签让用户知道操作语义 |
| 最小加载时长 | 显示延迟 ~150–300ms，最小可见 ~300–500ms | 避免闪烁；短于阈值的加载不显示指示器 |
| 省略号语义 | 打开后续步骤的菜单项、加载/处理状态用 `…` 字符 | 区分"立即执行"与"需要后续输入" |
| 破坏性操作 | 要求确认或提供 Undo 安全窗口 | 不可逆操作需二次确认或可撤销 |
| 乐观更新 | 预期成功时立即更新 UI；服务端响应后对账；失败回滚或提供 Undo | 感知速度优于等待服务端确认 |
| 异步更新通告 | toast 与内联校验用 `aria-live="polite"` | 屏幕阅读器用户感知动态变化 |
| 无死区 | 控件看起来可交互的部分必须可交互 | 视觉承诺与行为不一致损害信任 |

## 状态导航

| 要求 | 做法 | 为什么 |
|---|---|---|
| URL 即状态 | 筛选、标签、分页、展开面板等 `useState` 场景持久化到 URL | 支持分享、刷新、前进/后退恢复 |
| 链接用 `<a>` | 导航用 `<a>` 或框架 `<Link>`；不用 `<button>` 或 `<div onClick>` | 链接语义支持中键打开、右键菜单、SEO |
| 深链接 | 任何可分享的视图状态都应可深链接 | 用户期望直达特定视图 |
| 未保存变更 | 有未保存数据时导航前警告 | 防止意外丢失输入 |

## 自动聚焦与拖拽

| 要求 | 做法 | 为什么 |
|---|---|---|
| 桌面自动聚焦 | 单一主要输入的桌面页面可 autofocus | 减少一次点击，提升效率 |
| 移动慎用自动聚焦 | 移动端因键盘弹出导致布局偏移，一般不自动聚焦 | 虚拟键盘挤压视口 |
| 洁净拖拽 | 拖拽中禁用文本选择并对拖拽元素应用 `inert` | 防止误选文本与意外交互 |
| Tooltip 时序 | 一组 tooltip 中首个延迟显示；后续相邻项无延迟 | 鼠标在相邻项间移动时连续显示，不重复等待 |

## 水合与输入

| 要求 | 做法 | 为什么 |
|---|---|---|
| 水合安全 | 输入在水合后不丢焦或丢值 | 水合不匹配破坏交互连续性 |
| 禁用粘贴 | 不得在 `<input>`/`<textarea>` 禁用粘贴 | 禁用粘贴损害可用性与密码管理器 |
| 输入法空白 | 裁剪输入法添加的尾部空白 | 部分输入法追加空格，导致校验失败 |

## 快捷键国际化

| 要求 | 做法 | 为什么 |
|---|---|---|
| locale-aware | 非 QWERTY 布局下国际化快捷键；显示平台特定符号 | QWERTY 快捷键在 Dvorak/AZERTY 下不可用 |
| 平台符号 | macOS 用 ⌘、Windows/Linux 用 Ctrl | 匹配用户预期与肌肉记忆
