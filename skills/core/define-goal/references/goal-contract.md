# Goal Brief 合同

按目标复杂度保留必要字段，整体不得超过 4000 字符。目标里最致命的往往不是“要做什么”，而是“什么不能做”——先圈定禁区与判卷标准，再写正向目标，避免 AI 走到你没想到的捷径。

## 六段结构

1. **目标结果**：说明谁获得什么结果、为什么重要，以及冲突时的优先顺序；不要把实现手段冒充目标。
2. **事实与基线**：只写会改变执行的仓库事实、测量值、来源与日期；未验证内容明确标为假设。
3. **决定与假设**：记录已关闭的产品决定；低风险默认值用“问题 → 默认值（标‘猜的’）｜猜错代价”三段式标注，让用户一眼看到哪些是替他拍的决定、发出前可改；高影响未决项阻止激活。
4. **范围与禁区**：使用写入白名单，列出非目标、受冻结的判卷标准和仍需人工批准的动作。高风险目标同时冻结 riskClass、允许 effects、workspace identity 和无凭据 external targets。区分“法”与“情报”——“不许 / 只允许”违反即失败，“建议”可走更优路径但须记录原因。
5. **完成条件**：执行型使用结果指标、保护性指标、实际验证命令和防作弊约束；每项必需验收固定为 passed、failed、blocked、unverified，只有全部 passed 才能完整完成。探索型改为学习问题、来源或复现步骤、调查预算和未排除项。交付使用实际验证的简明证据摘要；仅在复现缺陷或实验对照需要时提供红→绿证据，不统一要求完整命令输出。
6. **停止与续跑**：声明无进展时的诊断或换路、回滚、必要人工门、恢复入口与诚实失败交付；预算和 Goal 状态使用宿主实际合同，不自行设定未请求的预算。授权、局部暂停、恢复和整个目标的 terminal condition 遵循 governance-core；不按累计三次失败自动终止目标。

## 执行型

- 每项验收包含命令或明确的人工判据及预期结果；命令未实测时标为待核对，由执行 Agent 在需要时验证，不强制创建任务 0。
- 不得为让变更通过而删除相关测试、放宽断言、替换被测对象或吞掉退出码；测试调整须保留约定的行为覆盖，覆盖率和跳过数用于诊断，不自动成为所有目标的数字门禁。
- 需要反向验证时，明确制造失败、观察告警、恢复并再验证；不能让验证过程留下 Git 可见改动。

## 探索型

- 把“目前最优结论”和“尚未排除项”作为合法交付；证明方向不可行也可完成。
- 每条结论附公开来源与日期，或十分钟内可复跑的步骤；限制来源数或时间预算，禁止无限调研。
- 不用虚构业务数字奖励确定答案，也不把未经验证的方案写成强制实现。

## 载体与激活

- 快速或轻量目标直接内联；已有完整 v3 任务时，目标只概括结果并引用任务路径。
- 用户只要草稿时不得写文件或激活目标。用户明确要求持久执行时，才使用宿主真实提供的目标操作。
- 原生目标已存在时先展示冲突并要求明确的编辑、完成或清除动作；无原生能力时返回一次可复制内容，不假装持久化。
- 原生 Goal 只写入宿主支持且用户授权的字段；其余必要边界使用宿主支持的上下文或可选记录。每次自动续跑核对已有 Goal 和当前任务状态；没有原生 Goal bridge 时不声称后台持续执行，用户继续请求或宿主显式续跑仍可恢复原范围工作。
- Goal 进入 complete 后不得自动派发补充审计、下一个节点或范围外验证；这些动作必须成为新的用户请求或新的原生 Goal。

## 大工作分解

工作量大到单个会话装不下、且决策尚未收敛时，Goal Brief 可附一张**决策地图**（本地 Markdown，默认载体；宿主有原生 issue 工具时可改用 tracker 票据，但不绑定具体 tracker、不引入 tracker API 依赖）。地图分四区：

- **Destination**：目标结果摘要，指向 Goal Brief 的目标结果段，不重写。
- **Decisions so far**：已关闭决策的标题加一行概要，再加指针（任务路径或 `DECISIONS.md` 条目）；正文不复制，地图只做索引。
- **Not yet specified**：还不能清晰表述成可执行验收的开放问题。问题一旦能写成可执行项就迁出此区进入任务列表；不能表述清楚的留下，直到变清晰。
- **Out of scope**：明确排除、不随本目标推进的事项；它们不"毕业"回地图，只在此声明。

地图是索引而非仓库：每条 Decision 只放标题、一行概要和指针，决策正文与证据落在对应任务或 `DECISIONS.md` 条目里，避免双份真值。在当前授权和可用上下文内持续关闭可解决的决定，不限制单会话决定数量；连续无有效进展按“停止与续跑”诊断或换路。地图是 Goal Brief 的可选附表，不强制，也不改变 4000 字符总约束。
