# Find Question 检查矩阵

每个候选都记录：对象、触发条件、期望、实际、证据、被破坏不变量、影响、证伪结果和边界。

| 领域 | 必查问题 | 常见静默缺陷 |
| --- | --- | --- |
| 契约/字段 | schema、接口、表单、提交载荷、导入和纠错是否同源 | 字段有契约但无入口；有入口但未提交；类型/枚举/单位分叉 |
| 逻辑/规则 | 条件优先级、阈值、默认值、异常分支是否可达且互斥 | 恒真校验、不可达规则、关键词拼接绕过、演示常量阻断 |
| 引用/消费 | 每个生产者是否有消费方，每个消费方是否有真实生产者 | 空引用、过期 ID、无消费配置、隐藏入口仍被判定依赖 |
| 一致性 | 单一事实源、事务、事件顺序、缓存、重试和并发是否有不变量 | 双写漂移、重复消费、缓存旧值、部分成功无补偿 |
| 配置/发布 | 默认值、环境覆盖、Feature Flag、灰度和回滚是否闭环 | 未知键静默忽略、环境默认不一致、关闭开关仍执行 |
| 授权/租户 | 认证、对象级/字段级权限、读写导出导入是否在服务端对称校验 | 只限制展示不限制写入；越权 ID 可访问；脱敏值被回写 |
| 生命周期 | 状态、迁移、终态、撤回、删除、恢复、幂等是否定义 | 终态可继续写、非法迁移、失败重试重复副作用、清理遗漏 |
| API/错误 | 请求响应、分页、错误码、超时、重试和兼容窗口是否一致 | 失败吞掉、错误码误导客户端、部分字段缺失被默认值掩盖 |
| 可观测性 | 关键拒绝、状态迁移、数据修正和外部调用是否可追踪 | 无审计、无关联 ID、告警条件不可达、恢复只能人工猜测 |

## 证伪动作

- 检索所有替代入口：UI、API、批量、导入、迁移、后台任务和脚本。
- 反向检索所有消费方：判定、展示、导出、统计、缓存、事件和日志。
- 对照默认值、配置覆盖、feature flag、权限中间件和测试 fixture。
- 优先运行无副作用的最小关键路径；失败只记录事实，不扩大为未证实影响。

## 深查动作

- 字段：列表单字段与 payload 差集，逐个反向追到 schema、赋值与消费；区分 null、undefined、空串、0、false，检查脱敏占位值回写。
- 规则：为相互作用的条件列真值表，测试阈值相等、日期时区、单位换算与优先级；从阻断结果反查用户可达的补录入口。
- 数据：沿写入→事务提交→事件发布→消费→缓存→展示画出时序；逐点推演失败、重复、乱序和并发，寻找丢更新与部分提交。
- 配置：建立定义→默认→环境覆盖→读取→生效矩阵；追踪开关开启和关闭两种状态，不能只搜索键名出现次数。
- 权限：建立主体×租户×对象×字段×操作矩阵；对照列表/详情/修改/导入/导出/后台任务，在服务端核对每条旁路。
- 生命周期：列状态、允许迁移、禁止迁移、资源 owner 与释放点；核对取消、超时、删除、失败重试及恢复后是否残留锁、订阅、句柄或重复任务。
- 负面证据：先检查动态注册、反射、外部 API 消费和生成映射；索引有缺口、分页未完成时只说“本范围未找到”，不能宣布全局无消费。
