# 纵深防御验证

当单点修复不足以防止问题复发时，用多层防线验证输入、业务规则、环境和诊断能力。

## 四层

1. 入口校验：外部输入、用户输入、文件、网络响应。
2. 业务逻辑校验：领域规则、状态转换、权限。
3. 环境保护：配置、feature flag、运行环境、迁移状态。
4. 调试证据：日志、错误信息、metrics、测试。

## 使用方式

- 先确认根因，再决定需要哪些层。
- 每层只承担自己的职责，不重复制造复杂性。
- 测试应覆盖最容易破坏的层。
- 错误信息要帮助定位，而不是吞掉上下文。

## 输出

```text
根因：...
入口防线：...
业务防线：...
环境防线：...
诊断证据：...
验证命令：...
```
