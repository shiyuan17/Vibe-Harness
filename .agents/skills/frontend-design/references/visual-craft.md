# 视觉工艺

视觉细节的具象技术与约定。令牌骨架见 `design-tokens.md`；组件状态变体见 `component-states.md`；强制门禁见 `docs/rules/frontend-rules.md`。

## 投影与边框

| 要求 | 做法 | 为什么 |
|---|---|---|
| 分层投影 | 至少两层：ambient（环境光，大面积柔散）+ direct（直射光，小面积锐利） | 单层投影扁平；分层模拟真实光照 |
| 清晰边框 | 边框与投影组合；半透明边框提升边缘清晰度 | 纯投影在浅背景上边缘模糊 |
| 色相一致 | 非中性背景上，边框/投影/文字向同一色相偏移 | 纯灰边框在彩色背景上显脏 |

## 圆角

| 要求 | 做法 | 为什么 |
|---|---|---|
| 嵌套圆角 | 子元素圆角 ≤ 父元素圆角，且同心 | 同心圆角视觉对齐；不等大圆角错位 |
| 圆角阶梯 | 用 `radius` 令牌阶梯（`radius.xs`→`radius.full`） | 禁止魔法值；见 `design-tokens.md` |

## 对比度与颜色

| 要求 | 做法 | 为什么 |
|---|---|---|
| 最小对比 | 优先 APCA 而非 WCAG 2 | APCA 更准确反映感知对比度（尤其暗色文本） |
| 交互增对比 | `:hover`/`:active`/`:focus` 比静止态对比更高 | 反馈状态需更醒目 |
| 无障碍图表 | 用色盲友好调色板 | 红绿配色对色盲用户不可辨 |
| 冗余提示 | 不只靠颜色传达状态；附文字或图标 | 色盲与低视觉用户依赖非色觉通道 |

## 暗色模式与主题

| 要求 | 做法 | 为什么 |
|---|---|---|
| `color-scheme` | 暗色主题在 `<html>` 设 `color-scheme: dark` | 滚动条、表单控件等设备 UI 自动适配 |
| `theme-color` | `<meta name="theme-color">` 匹配页面背景 | 浏览器 UI（地址栏）与页面融合 |
| 令牌映射 | 暗色模式只改令牌映射值，不改组件结构 | 见 `design-tokens.md`；保证单一数据源 |
| Windows `<select>` | 显式设置 `background-color` 和 `color` | Windows 下默认值在暗色模式对比度异常 |

## 文本渲染

| 要求 | 做法 | 为什么 |
|---|---|---|
| 动画 wrapper | 优先动画 wrapper 而非文本节点 | 直接变换文本触发抗锯齿退化 |
| 提升合成层 | artifacts 持续时用 `translateZ(0)` 或 `will-change: transform` | 强制独立合成层，改善渲染 |
| 谨慎 `will-change` | 只在实际将变化时设置，用后移除 | 滥用消耗内存与合成层资源 |

## 渐变与背景

| 要求 | 做法 | 为什么 |
|---|---|---|
| 避免 banding | 渐变到深色时用背景图代替 CSS mask | CSS mask 在深色渐变上出现色带 |

## 布局对齐

| 要求 | 做法 | 为什么 |
|---|---|---|
| 光学对齐 | 感知优于几何时调 ±1px | 几何精确但视觉偏移时，光学修正更自然 |
| 刻意对齐 | 每个元素对齐到网格、基线、边缘或光学中心 | 无对齐则视觉松散 |
| 图文锁扣 | 文字与图标并排时调字重、字号、间距或颜色 | 防止视觉重心失衡
