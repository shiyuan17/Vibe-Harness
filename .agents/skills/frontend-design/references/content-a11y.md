# 内容与可访问性

内容呈现与可访问性的具象技术。强制门禁见 `docs/rules/frontend-rules.md`；组件状态变体见 `component-states.md`。

## 语义优先

| 原则 | 做法 | 为什么 |
|---|---|---|
| 语义先于 ARIA | 优先用原生元素（`button`/`a`/`label`/`table`/`nav`/`main`），再考虑 `aria-*` | 原生元素自带键盘、焦点与语义，ARIA 不补全行为 |
| 不暴露 schema | 视觉可省可见标签，但 accessible name 仍存在 | 视觉简洁与辅助技术可访问兼顾 |
| heading 层级 | `<h1>`–`<h6>` 层级递进，不跳级 | 屏幕阅读器用户靠 heading 导航结构 |
| skip link | 提供"跳到主内容"链接 | 键盘用户跳过重复导航 |

## 标签与命名

| 要求 | 做法 | 为什么 |
|---|---|---|
| 图标有标签 | 纯图标按钮提供 `aria-label`，描述性文本与图标同义 | 非视觉用户需要名称 |
| 装饰图标 | 纯装饰元素用 `aria-hidden="true"` | 避免辅助技术朗读噪音 |
| 可访问名称 | 在可访问性树中验证每个交互元素有名称 | 无名称的控件不可操作 |
| 冗余状态提示 | 不只靠颜色传达状态；附文字或图标 | 色盲用户无法感知纯色编码 |

## 内容排版

| 要求 | 做法 | 为什么 |
|---|---|---|
| 弯引号 | 用 curly quotes（" "）而非 straight quotes（" "） | 排版规范，提升可读性 |
| 省略号字符 | 用 `…` 而非三个句点 `...` | 单字符占位正确，间距一致 |
| 制表数字 | 数据对比列用 `font-variant-numeric: tabular-nums` 或等宽字体 | 等宽数字对齐，便于比较 |
| 非换行空格 | 单位、快捷键、品牌名用 `&nbsp;` 连接（`10&nbsp;MB`、`⌘&nbsp;K`） | 防止数字与单位、符号与键位断行 |
| 孤行/寡行 | 用 `text-wrap: balance`（标题）避免孤行寡行 | 提升排版美感 |
| 锚定标题 | 标题设 `scroll-margin-top` | 固定头部不遮挡锚跳转目标 |

## 标题与状态

| 要求 | 做法 | 为什么 |
|---|---|---|
| 准确 `<title>` | 反映当前上下文（如"编辑用户 - 管理后台"） | 标签页、书签、SEO 依赖标题 |
| 稳定骨架 | skeleton 镜像最终内容结构 | 避免加载完成后的布局偏移 |
| 全状态设计 | empty、sparse、dense、error 状态都有设计 | 不留未定义的空白屏幕 |
| 无死路 | 每个屏幕提供下一步或恢复路径 | 用户不会卡在无出口的视图 |
| 内联帮助优先 | 优先内联说明；tooltip 作为最后手段 | tooltip 需悬停、触屏不可达、屏幕阅读器支持不一 |
| UGC 韧性 | 布局容纳短、平均、极长内容 | 用户生成内容长度不可预测 |

## 本地化

| 要求 | 做法 | 为什么 |
|---|---|---|
| locale 格式 | 用 `Intl.DateTimeFormat`/`Intl.NumberFormat` 格式化日期、数字、货币 | 硬编码格式在跨 locale 下错误 |
| 语言由设置 | 用 `Accept-Language` header 和 `navigator.languages` 检测；不依赖 IP/GPS | 位置不等于语言偏好（旅行、外籍用户） |
| 免翻译标记 | 品牌名、代码 token、标识符用 `translate="no"` 包裹 | 防止机器翻译破坏专有名词 |
| 货币一致 | 同上下文用 0 或 2 位小数，不混用 | 混用小数位造成阅读负担 |

## 可访问性验证

| 要求 | 做法 | 为什么 |
|---|---|---|
| 验证可访问性树 | 在浏览器可访问性面板检查名称、角色、状态 | DOM 结构不等于可访问性呈现 |
| landmark | 用 `header`/`nav`/`main`/`aside`/`footer` 划分 | 辅助技术靠 landmark 快速跳转 |
| 对比度 | 正文与控件达可访问对比度；优先 APCA 而非 WCAG 2 | APCA 更准确反映感知对比度
