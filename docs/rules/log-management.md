# 可观测性与日志管理规则

本规则只定义项目发现、关联、安全与可靠性底线，不替代目标项目的日志或遥测契约；具体 logger、采集器、存储、查询方式、字段命名和服务等级由目标项目决定。

## 目标与边界

- 新增日志、指标或追踪前必须说明消费目的，例如查询、告警、排障假设或审计要求；没有消费价值的信号应删除或降采样。
- 先读取项目专项规则中的日志画像，再定位实际 logger、配置、输出来源、查询入口和验证方式；候选证据指仓库中发现但未经运行验证的线索，候选证据不能直接当作运行事实。
- 沿用项目已有 logger、格式、输出与查询方式；没有明确需求时不引入新日志库、追踪系统或存储后端。
- 画像为 unknown 时搜索 logger 初始化、配置、项目脚本和部署清单，明确未确认项，不编造生产位置或平台命令。
- 遥测只保留运行、排障、安全和可靠性所需的最小上下文，不得记录业务载荷或为未知用途预留数据。
- 告警和排障结论必须能回到实际查询、关联字段或验证证据，不以缺少遥测证明系统健康；认证失败、权限拒绝、输入拒绝等安全相关拒绝事件必须可观测。

## 最小字段与关联

- 新增应用日志优先使用结构化格式，推荐 JSON Lines；公共字段包含时间、级别、service/component、event/operation、结果和 environment/version；时间使用带偏移的 UTC 时间戳，多主机部署要求时钟同步，查询时区随窗口一并记录。
- 日志级别和字段语义必须在系统内一致：级别取值限定为 debug/info/warn/error/fatal，并明确每类事件落到哪一级；error 保留给需要人工介入或违反不变量的事件。已有实现可以使用等价字段映射。
- error code、安全错误消息、耗时、任务类型、attempt、协议状态和安全上下文仅在事件适用时记录，普通事件不强制携带错误字段。
- 项目已有 trace context 时同时记录 `traceId` 和 `spanId`；`correlationId` 不能替代 trace context；不得仅为日志关联引入 tracing。
- 采样不得丢弃错误、安全与审计信号；被采样丢弃的事件保留计数或标记，使比例仍可计算。

## 指标与追踪底线

- 结果指标必须同时提供总量，使成功率或错误率可计算；延迟使用分布并区分成功与失败，不只记录平均值。
- metric label 只使用有界、稳定、可聚合的值；禁止使用用户 ID、请求 ID、邮箱、完整 URL、原始错误消息或其他高基数值。
- trace context 应跨入口、下游调用、重试和异步消息传播；无法传播时记录断点和替代关联方式，不伪造父子关系。
- 采样、基数和成本控制不得静默改变已声明的运行、安全或审计语义。

## 安全与可靠性

- 来自其他信任区的字段在写入前必须校验、限长、编码和脱敏，过滤 secret、token、cookie、authorization header、凭据、原始 PII、消息体和不必要业务数据。
- 清理或安全编码 CR/LF、分隔符和控制字符，防止日志注入、伪造记录和解析器逃逸；展示端仍将日志视为不可信输入。
- 运维日志、安全事件、审计轨迹和业务分析数据按目的分离，并分别定义访问权限、完整性保护（只追加存储、篡改可检测）、留存期限和到期删除（删除可验证）。
- 日志或遥测后端故障不得阻塞核心业务，也不得以无限内存、磁盘或同步重试拖垮应用；强一致审计由目标项目单独定义 fail-closed 边界。
- `.vibe-harness/log/` 只保存 Harness 或临时捕获输出，不代表目标应用日志目录；截图、trace 导出和报告等证据写入 `.vibe-harness/artifacts/`。

## 排障与验收

1. 记录症状、绝对时间窗口（含时区）、环境和近期变更，先用用户结果或关键状态确定影响；诊断流程与 troubleshooting 规则分工，本规则只约束日志与遥测侧收敛方式。
2. 按时间、环境、组件、事件、结果、`traceId` 或错误码收敛证据，并将证据连接到可验证假设；证据冲突时更新假设。
3. 修复后运行对应验证，确认受影响信号恢复，并记录实际查询条件和验证证据；高基数维度不进入日志索引。

验收检查不超过以下六项：

- 目的：每项信号有明确消费方。
- 字段：公共字段完整，条件字段只在适用时出现。
- 指标：结果有分母，延迟有分布，label 有界。
- 关联：同步和异步边界可追踪，传播断点已说明。
- 安全：输入已限长、编码、脱敏并按权限和期限保存。
- 证据：交付包含实际查询条件、关键摘要和修复后验证。

信号互相冲突或遥测不足时先缩小结论并继续可用的静态证据和安全查询。只有继续调查需要额外检索或生产权限、无法安全处理敏感数据、不可逆操作或扩大授权范围时停止并升级。
