# 决策

记录长期有效的决策。每条包含 ID、日期、决策、证据、影响和复核条件。

## 条目格式

- **[ID]** 标题 - 一行概要
  - 日期：
  - 证据：（命令输出、来源链接、基线测量）
  - 影响：（受影响的接口/文件/行为）
  - 复核条件：（何时重新评估）
  - 指针：（任务路径或 issue 链接，可选）

## 纪律

- 这里只存已关闭的长期决策；当轮可关闭的解阻走 clarify-requirements，不进此文件。
- 索引而非仓库：标题加一行概要留在此文件，决策正文与证据落在对应任务或交付记录里，不复制全文。
- 明确排除的项记录在各自范围的 Out of scope，不在此累积。
