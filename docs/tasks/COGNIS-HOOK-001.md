## 剩余风险

白名单授权的外部目录可被 Hook 允许结构化写入；目录所有者应仅配置受信任的协作项目路径。任意 Shell 命令不具备通用、跨平台的写入路径解析，仍应通过 Codex 审批与项目命令边界控制。路径检查与实际写入之间仍存在本地文件系统 TOCTOU 风险，Hook 仅作为纵深防御，不替代沙箱。
