# 审查工作流

用于独立审查。审查 Agent 默认只读，先列问题，再核对 diff 范围、行为、测试、验证证据和规则合规性。

## 阶段目标

独立判断变更是否满足规格、规则、验证和风险要求，避免实现者自证高风险工作通过。

## 输入内容

- Spec、Plan、Task 或用户请求。
- 当前 diff、目标分支和相关文件。
- 验证证据：命令、退出码、关键输出、截图或人工核对。
- 工作流交付包和风险等级。

## 输出内容

- 审查包。
- 问题列表，按严重度排序并引用文件/行号或证据来源。
- 已核对验证、未覆盖风险、待确认问题。
- 审查结论：`Approve`、`Request changes` 或 `Blocked by missing evidence`。

## 完成标准

- 先列问题，再写摘要。
- 每个阻断问题都有原因、影响和建议修复方向。
- 无 finding 时明确说明剩余测试缺口或残余风险。
- 审查不替代红区人工确认。

## 常见异常

- 缺少 diff、规格或验证证据。
- 验证命令只覆盖局部，无法证明整体目标。
- 审查者发现范围外问题。

## 异常处理方式

- 证据缺失时返回 `Blocked by missing evidence`，不猜测通过。
- 覆盖不足时要求补验证或降低完成声明。
- 范围外问题记录为后续任务，除非它直接阻断当前变更安全性。
