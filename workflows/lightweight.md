# Lightweight 工作流（轻量流程）

用于不触及红区、安全、数据库、生产、发布或跨层契约的低风险实现。Lightweight 适合单一职责、小范围、可用聚焦测试证明的改动。

## 阶段目标

在明确边界内完成低风险实现，并用聚焦验证证明目标行为已达成。

## 输入内容

- Task Intake：目标、非目标、验收标准、风险等级。
- Write Scope 和 Forbidden Actions。
- 相关规则、模板、现有代码或文档上下文。
- 验证命令：聚焦测试、lint、typecheck 或治理检查。

## 输出内容

- Diff 或文档变更说明。
- Workflow Packet：主 workflow、触发信号、必要修饰器、验证、剩余风险。
- 验证证据：命令、退出码、关键输出。
- Handoff 或下一步最小动作（存在未完成项时必填）。

## 完成标准

- 所有验收标准都有证据覆盖。
- 没有越过 Write Scope，未覆盖用户无关改动。
- 未触发 Full 工作流升级条件。
- 聚焦验证通过；无法运行的验证有明确原因和替代核对方式。

## 常见异常

- 实现中发现外部契约、跨层依赖或红区文件。
- 聚焦测试失败且修复需要扩大范围。
- 目标项目已有冲突改动或 worktree 状态不清。

## 异常处理方式

- 命中 Full 触发器时停止当前档位，补充 Full Packet。
- 验证失败时记录 Failure Packet：失败命令、退出码、关键输出、下一步安全动作。
- Git 状态不清时暂停编辑，先澄清归属或隔离 worktree。
