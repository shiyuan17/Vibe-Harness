# Skill Routing

Skill 只补强项目规则，不覆盖红区确认、验证、审查或真值来源规则。

## 路由

- Clarify：brainstorming 或 task-intake 类 skill。
- 规格：涉及契约时使用接口/设计类 skill。
- 计划：多步骤工作使用 writing-plans 类 skill。
- Execute：使用 TDD 和 debugging 类 skill。
- Verify：使用 verification-before-completion 和 browser check。
- Review：使用 code review 或 security review 类 skill。
- 交接：使用交接模板或 memory 集成。

选择最小有用 skill 集，并说明每个 skill 为什么启用。
