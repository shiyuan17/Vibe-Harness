# 任务启动模板

填写规则：标记“必填”的字段不得留空；禁止空泛词（待定、视情况、合适测试、后续补充）。验收标准不清、红区确认缺失或写入范围不明时不得进入执行阶段。

- 来源：
- 编号 / 标题（必填）：
- 任务模式（必填：`single` / `parent` / `child`）：
- 父任务 ID（child 必填）：
- 链接：
- 目标（必填）：
- 验收标准（必填）：
- 非目标（必填）：
- 影响范围（必填）：
- 工作流档位（必填：`Fast Path` / `Lightweight` / `Full`）：
- 主工作流（必填）：
- 必要修饰器：
- 风险等级（必填：低 / 中 / 高）：
- Worktree 决策（必填）：
- 验证命令（必填）：
- 停止条件（必填）：

## 拆分判断

- 是否需要父子任务（必填：需要 / 不需要）：
- 判断依据（必填：小任务单闭环，或多 agent / worktree / Full / 高风险 / 多交付物 / 并行写入范围）：
- 最小可审查闭环（必填）：
- 是否存在过细拆分（必填：无；如有，合并到可交付 child）：
- 5 分钟判断（必填：能在约 5 分钟内完成，或能明确阻塞和下一步）：

- 回滚方案：

## 写入范围

- 允许范围（必填）：
- 禁止范围（必填）：
- 需要人工确认：
- 冻结接口：

## 禁止动作

- 不覆盖用户未归属改动。
- 不伪造 API、字段、权限、schema、测试结果或发布结果。
- 不绕过测试、hook、review 或红区确认。
