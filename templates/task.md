## 完整流程控制

完整档位填写以下 v2 JSON；其他档位删除本节。父任务必须补齐子任务、执行批次、集成验证、时间盒分钟和冲突任务；子任务必须补齐父任务编号、输入、固定输出格式、不得修改范围、时间盒分钟和冲突任务。执行批次之间串行，同一批次仅允许无冲突、写入范围不重叠的任务并行。

```json
{
  "控制版本": 2,
  "任务类型": "单任务",
  "责任角色": "实现负责人",
  "写入范围": ["src/example.js"],
  "禁止动作": ["覆盖用户未归属改动"],
  "输入": ["无"],
  "输出格式": ["交付记录中的变更、验证和风险"],
  "不得修改范围": ["写入范围之外的所有文件"],
  "依赖任务": [],
  "冲突任务": [],
  "并行安全": "独占写入",
  "时间盒分钟": 60,
  "停止条件": "验收标准全部获得有效证据",
  "回滚方案": "恢复修改前文件",
  "人工确认": "不需要",
  "核验者": "独立核验者",
  "红队审查者": "独立核验者",
  "红队审查包": "docs/reviews/<任务编号>-red-team.md",
  "红队审查结论": "待审查",
  "合并回主线状态": "不需要"
}
```

v2 子任务的输出格式固定为 `["状态", "变更摘要", "变更路径", "验证证据", "未验证项", "剩余风险", "下一步动作"]`。无 `控制版本` 的历史控制块按 v1 继续读取；新任务不得省略版本。

旧的未完成完整任务可暂不填写红队字段；处理结果改为“完成”前必须补齐字段、生成审查包并将结论更新为“批准”。
